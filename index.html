Automated Website Deployment

A practical DevOps project demonstrating how GitHub, webhooks, Jenkins and Docker work together to automate website delivery and reduce manual deployment effort.

Explore the Pipeline

Technology Stack

Git & GitHub

Version control and source-code management for tracking website changes.

Webhooks

Notify Jenkins when a new change is pushed to the repository.

Jenkins

Automates the build and deployment process through a CI/CD pipeline.

Docker

Packages the website into a container for consistent execution.

Apache HTTP Server

Serves the deployed static website to users through a web browser.

Linux / Ubuntu

Provides the environment for running Jenkins, Docker and deployment tasks.

Deployment Workflow

01 Developer updates website files.

02 Changes are pushed to GitHub.

03 GitHub webhook triggers Jenkins.

04 Jenkins executes the pipeline.

05 Docker builds the website image.

06 The website container is deployed using Apache.

07 Users access the updated website through the server IP.

Project Objective

The objective of this project is to understand CI/CD automation by integrating source-code management, webhook-based triggers, Jenkins pipelines and Docker containerization. The workflow helps make deployments repeatable, efficient and easier to maintain.
